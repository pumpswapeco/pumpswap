# Pumpswap

Pumpswap No Code Solana Staking Infrastructure is a Solana staking platform for projects to create, configure, and manage non-custodial staking pools.

## Features

- Solana staking pools
- Fixed staking rewards
- Multiple staking pools
- Reward funding and distribution
- NFT-based staking boosts
- Pool pause and emergency freeze controls
- Token-2022 and standard SPL Token support
- White-label staking portals
- Admin dashboard
- On-chain Anchor staking program
- Solana devnet support
